# 🖌️🗃️ CRM Design

Projeto em desenvolvimento para organizar clientes, marcas e,
futuramente, o acompanhamento comercial de um designer gráfico.

Estou construindo o sistema gradualmente para estudar Python,
backend, bancos de dados e testes automatizados.

## 💡 Funcionalidades atuais

- Representação de cliente e marcas com dicionários e listas.
- Busca de marcas pelo ID do cliente.
- Verificações automatizadas com assert.

## 👩🏻‍💻 Tecnologias utilizadas

- Python

## 📍 Como executar

Na pasta do projeto, execute a demonstração:

```bash
python main.py
```

Para executar os testes:

```bash
python test_servicos.py
```

## 📂 Organização dos arquivos

- main.py: dados fictícios e execução da demonstração.
- servicos.py: funções com as operações do CRM.
- test_servicos.py: dados de teste e verificações automatizadas.
